# PepsiCo Smart Cashback

Продуктовый кейс по разработке cashback- и loyalty-механик для FMCG-брендов PepsiCo.

Цель проекта — определить, какие механики лояльности могут увеличить продажи, частоту повторных покупок и вовлечённость пользователей в e-commerce, а затем разработать конкретные инициативы для брендов Агуша, Lay’s и Adrenaline Rush.

## Задача

Разработать систему cashback-механик для трёх брендов PepsiCo с учётом:

- особенностей целевой аудитории;
- типа покупательского поведения;
- существующих программ лояльности;
- каналов продаж;
- экономики инициатив;
- возможностей банков и онлайн-ритейлеров.

Основной принцип проекта — не использовать одну cashback-механику для всех продуктов, а подобрать решение под особенности каждого бренда.

## Подход

Работа над кейсом включала несколько этапов:

1. анализ рынка программ лояльности;
2. анализ cashback-механик банков и ритейлеров;
3. исследование особенностей трёх брендов;
4. определение наиболее подходящих механик;
5. приоритизация инициатив;
6. разработка механики запуска;
7. финансовая оценка;
8. формирование roadmap.

## Анализ программ лояльности

В рамках исследования были рассмотрены механики банков, маркетплейсов и ритейлеров.

Анализировались:

- денежный cashback;
- cashback бонусами;
- категории повышенного cashback;
- многоуровневые программы;
- накопительные механики;
- программы для отдельных клиентских сегментов;
- cashback от партнёров;
- loyalty-механики внутри экосистем.

Среди рассмотренных платформ и компаний:

- T-Банк;
- Ozon;
- X5;
- Магнит;
- Яндекс Плюс;
- другие банковские и retail-программы.

## Роль cashback-механик

На основе анализа были выделены несколько основных задач cashback:

- стимулирование повторных покупок;
- увеличение частоты покупок;
- повышение потребления категории;
- привлечение новой аудитории;
- рост лояльности;
- стимулирование спонтанных покупок;
- защита аудитории от перехода к конкурентам;
- увеличение доли бренда в e-commerce.

## Анализ брендов

Для разработки инициатив были выбраны три бренда с разными моделями потребления:

### Агуша

Детское питание относится преимущественно к плановым покупкам.

Для такой категории особенно важны:

- повторные покупки;
- долгосрочная лояльность;
- накопительный эффект;
- регулярность взаимодействия с брендом.

Поэтому для Агуши основной фокус был сделан на многоступенчатом cashback и бонусных программах.

### Lay’s

У Lay’s сильные позиции в офлайн-продажах, при этом e-commerce создаёт дополнительный потенциал для роста.

Для продукта характерна возможность стимулировать импульсное потребление и совместные покупки с напитками.

Одним из ключевых направлений стала механика cashback на продуктовые комбо.

### Adrenaline Rush

Значительная часть продаж энергетических напитков связана с сервисами быстрой доставки.

Для бренда были рассмотрены механики:

- cashback на комбо;
- повышенный cashback;
- категории месяца;
- многоступенчатые программы.

## Ключевые инициативы

После анализа были предложены несколько продуктовых механик.

### 1. Многоступенчатый cashback для Агуши

Размер cashback увеличивается в зависимости от общей суммы или количества покупок за период.

Пример логики:

```text
Базовый уровень → 3–8%
Оптимальный → 5–10%
Максимальный → 7–16%
```

Такая механика стимулирует пользователя возвращаться к бренду и увеличивать частоту покупок.

Дополнительно рассматривался cashback до 10% на Агушу в рамках ограниченного периода акции.

## 2. Ozon «Бонусы продавца» для Агуши

Механика использует существующую инфраструктуру Ozon.

Пользователь получает бонусы за покупку товаров Агуши и может использовать их при последующей покупке товаров бренда.

Основная задача:

- стимулировать повторные покупки;
- удерживать пользователя внутри бренда;
- использовать уже существующую loyalty-инфраструктуру маркетплейса.

## 3. Cashback на комбо Lay’s + Adrenaline Rush

Для двух продуктов была предложена совместная cashback-механика.

Пример:

```text
Lay’s + Adrenaline Rush
Cashback — 5%
```

Механика рассчитана на стимулирование совместной покупки снека и напитка.

Площадки:

- Самокат;
- Яндекс Лавка;
- Пятёрочка Доставка.

## 4. «Категория месяца»

Для брендов были предложены временные периоды повышенного cashback в партнёрских программах.

Например:

- Lay’s — категория месяца;
- Adrenaline Rush — категория месяца;
- Агуша — категория месяца.

Цель — временно увеличить привлекательность категории и стимулировать дополнительный спрос.

## 5. Детский клуб X5

Для Агуши была рассмотрена интеграция с программой «Детский клуб X5».

Такое решение позволяет работать непосредственно с основной целевой аудиторией бренда и использовать уже существующую loyalty-механику ритейлера.

## Приоритизация

Инициативы сравнивались с точки зрения:

- потенциального влияния на продажи;
- влияния на лояльность;
- соответствия поведению целевой аудитории;
- стоимости реализации;
- доступности инфраструктуры;
- масштабируемости.

В результате для разных брендов были выбраны разные механики вместо универсального cashback-решения.

## Продвижение

Для продвижения cashback-программ были предложены:

- push-уведомления банков и платформ;
- e-mail-рассылки;
- реклама в VK;
- Telegram-каналы;
- коммуникации внутри маркетплейсов;
- коммуникации внутри retail-приложений.

Это позволяет взаимодействовать с пользователем непосредственно перед покупкой или в момент выбора продукта.

## Roadmap

Для инициатив был разработан календарный план внедрения.

Он включал:

- заключение договоров с партнёрами;
- подготовку рекламной кампании;
- запуск cashback для отдельных брендов;
- запуск механик в X5;
- запуск механик через T-Банк;
- использование Ozon;
- тестирование различных периодов и форматов;
- анализ результатов.

Инициативы распределялись по времени, что позволяет тестировать механики последовательно и анализировать их эффект.

## Финансовая модель

Для инициатив была рассчитана прогнозная экономика.

### Агуша

- **прогнозируемый рост продаж:** 19,61%;
- **ROI:** 118,95%.

Отдельная cashback-механика для e-commerce также показала потенциальный рост выручки Агуши на 12,6%.

### Lay’s

- **прогнозируемый рост продаж:** 38%;
- **ROI:** 112,04%;
- **затраты:** 71,6 млн ₽;
- **срок окупаемости:** около 6 месяцев.

### Adrenaline Rush

- **прогнозируемый рост продаж:** 55,39%;
- **ROI:** 112,80%;
- **затраты:** 65,4 млн ₽;
- **срок окупаемости:** около 6 месяцев.

Показатели являются результатами расчётной модели кейса и зависят от использованных в модели предпосылок.

## Комбо-механика

Отдельно оценивалась инициатива Lay’s + Adrenaline Rush.

В расчётной модели:

- совместное размещение продуктов увеличивает продажи;
- наличие cashback дополнительно стимулирует покупку;
- комбинированная механика создаёт возможность кросс-продажи между двумя брендами.

Таким образом, cashback используется не только как скидочный инструмент, но и как способ управлять составом корзины покупателя.

## Результат

Вместо единой программы cashback была разработана система механик, учитывающая различия между брендами.

### Для Агуши

Основной акцент:

- повторные покупки;
- накопительный cashback;
- Ozon «Бонусы продавца»;
- программы для семейной аудитории;
- долгосрочная лояльность.

### Для Lay’s

Основной акцент:

- рост e-commerce;
- комбо-механики;
- стимулирование дополнительных покупок;
- категории повышенного cashback.

### Для Adrenaline Rush

Основной акцент:

- quick-commerce;
- cashback на совместные покупки;
- многоступенчатые механики;
- повышенный cashback в отдельных периодах.
